Current Firefox session

This feature reads the 5-hour and weekly allowances for the ChatGPT account signed in to your normal Firefox profile.

Private endpoint: ChatGPT does not document this endpoint, so it may stop working after a ChatGPT update. The extension requests the current Firefox session and uses its access token in memory only for the fixed usage request. The token is never stored, logged, synchronized, or shown.
