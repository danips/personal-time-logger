Experimental account usage

This feature keeps each signed-in ChatGPT account in its own Firefox container and reads the current plan allowance from ChatGPT.

Private endpoint: ChatGPT does not document this endpoint, so it may stop working after a ChatGPT update. When Firefox's isolated request cannot use the container session, a fixed request runs in the ChatGPT page context and reads the current session's access token in memory only to authenticate that request. The token is never returned to the extension, stored, logged, synchronized, or shown. ChatGPT can observe or modify that page-context data flow.

Optional: Firefox’s built-in containers are sufficient. If you do not already use Mozilla’s Multi-Account Containers extension, you may install it to make container management easier.
